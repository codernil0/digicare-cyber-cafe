## GitHub Pages deployment

This repository includes an automated GitHub Actions workflow at `.github/workflows/pages.yml`.

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, select **GitHub Actions** as the source if it is not already selected.
3. Every push to the `main` branch automatically builds and deploys the static website.
4. You can monitor the deployment under the **Actions** tab.

Expected website URL: https://codernil0.github.io/digicare-cyber-cafe/

The site is static HTML, CSS and JavaScript. No build step or server is required.
