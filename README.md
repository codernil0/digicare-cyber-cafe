## GitHub Pages deployment

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`.
4. Save. The website will be published at `https://codernil0.github.io/digicare-cyber-cafe/`.

The site is static HTML, CSS and JavaScript. No build step or server is required.
